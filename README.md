# Thai House Rental Contract Form

A standalone, client-side Thai house rental contract form. The app has a live A4 contract preview, browser-local draft saving, copy-to-clipboard, reset, and print / Save as PDF controls.

## Run locally

Open `index.html` directly in a browser or serve this directory with any static HTTP server. No build step or dependencies are required.

## Privacy

Form values are saved in the current browser's `localStorage`; there is no server-side form submission or database.

## Print / PDF

Use the print button in a browser with print support, then select **Save as PDF** in the system print dialog. Embedded app browsers may not expose printing; open the site in your device's full browser if needed.
